The modeling framework from the Industrial Sustainability Analysis Laboratory (ISAL) User manual can be found at archetypes/User manual archetypes.ipynb 

'archetypes_list' contains the current list of archetype models in a python code.
'base' contains the base code required to run these archetypes, as well as some codes used for examples in the user manual.

The report for project in which the models were developed can be found at https://www.2035initiative.com/clean-heat with suggested citation:
The 2035 Initiative. The Clean Heat Climate Opportunity: A Roadmap for Electrifying 
Low- and Medium-Temperature Industrial Heat. December 2025.
